# T1：观察驱动的下一工具行动候选

状态：离线研究合同；不是训练授权，也不是生产数据服务。唯一实现基线为 R0 `e389b6aac80ea5260db9879efdd6ec2651d37a50`。原 79 个 JS/MJS 模块以 `r0-module-hashes.json` 固定，原 291 项回归入口和标准不变。

## 第一阶段能力与边界

Student 首先值得学习的是：在权限约束内读取环境反馈，再选择一个可验证的只读动作。T1 只检验其最小子问题：第一次 `evidence.read` 返回有事实时选择 `evidence.assess`，返回空结果时选择一次受限复读。事实存在不等于证据充分、财务事实正确或信用风险可评估。

当前 M4 Runtime 已把这条二分规则写入行动门控，模型上下文只有结果计数，没有金融原文。因此，这些样本只能监督固定策略的行动选择；不能用于宣称学会金融推理、证据评价或自主研究。长期目标应扩展为有充分环境信息的证据使用能力，不能通过更换任务 ID 扩大当前数据。

只采用 **下一动作 SFT**。没有 Preference、RL、奖励模型、训练程序或隐藏推理文本。Teacher 是注入式 HTTP 的确定性合成决策器，没有真实 DeepSeek 采样。第一轮无观察的启动动作被排除，第二轮才有输入与可对照的动作；完成与停止是 Runtime 决定，不能伪装成模型输出。

## 数据的两层表示

模型候选 `flowcredit.action-sft/t1-v1` 使用三条 `messages`：固定 system，严格白名单 user 输入，以及实际签名 Plan 中的 assistant 行动。输入只有固定策略版本、上次工具、证据是否存在；目标只有工具名称和空参数。

```json
{"policy":"presence-then-assess-otherwise-one-reread/t1-v1","prior":{"tool":"evidence.read","evidencePresence":"present"}}
```

对应目标：`{"arguments":{},"tool":"evidence.assess"}`。这是**为窄任务重新构造的脱敏上下文**，不是原供应商请求的逐字重放。无任务标识、公司名、地址、哈希、费用、未来观察、最终状态、标签或金融文本进入模型输入。

受保护的本地审计旁表单独保存：样本哈希、原始轨迹封存哈希和身份、Evidence 修订和来源哈希、三种原合同版本、第二轮 child/request/receipt/plan/step 身份、前后观察哈希、预算预留与费用报告状态、候选归属、拒绝原因与导出许可。原轨迹保留时间、事件、工具反馈和完整 provenance；旁表通过封存引用追溯。公开样例只包含经过白名单校验的两行候选，不包含旁表或原始记录。

## 三种质量必须分开

| 维度 | 标签来源 | T1 能证明什么 |
| --- | --- | --- |
| 执行 | 当前 Runtime 重验、可信收据、成功工具结果、T0 终态复算 | `verified-success` 或 `insufficient-evidence`，以及动作实际执行 |
| 策略 | 独立书写的 prefix-only oracle，不导入 Teacher 的决策函数或 Runtime expectedAction | 当前固定规则的一致性；不证明最优性 |
| 金融事实 | 需要独立来源核验；模型自评无效 | `not-evaluated`。合成夹具中算术结果可复算，但没有真实世界事实 Gold |

正例有两种：完成的非空证据流程中的复核动作；两次经 Runtime 确认的空读取中的第二次读取。后者仅为新用途 `offline-second-action-policy-research` 的策略行动候选，T0 的 `insufficient-evidence` 标签、研究未完成结论和零行导出全部不变。

失败轨迹与未知调用不得进入正向行动 SFT。错误行动保留为拒绝审计，不直接输出为 assistant 训练目标。缺少已提交 capture、可信匹配 receipt、当前权限、来源许可，或发生状态漂移、篡改、预算未确认时，拒绝候选或阻断整次发布。

## 来源、许可与隐私

允许来源是封闭的合成夹具集合：继承的人工财务 HTML，以及两个无来源、无事实的合成空实体。财务 HTML 的字节哈希和实体与夹具声明必须匹配；不把 Runtime 的 `dataKind` 字符串当作权利证明。来源变更、修订迁移和真实外部文档不自动获准。

每次构建需要可信主机批准新的 T1 用途，绑定 schema、corpus、候选 dataHash、auditHash、每条当前 snapshot、principal 与来源声明；批准有时限。T0 导出许可不能代替 T1。合成许可辅助函数不是通用数据许可判断器；真实采样的法律、个人信息和第三方数据权利仍未解决。未决定新的开源许可证。

模型数据只允许固定枚举及空参数，额外字段、未来信息与自由文本均拒绝。原始数据、旁表、许可和导出保存在 0700 目录、0600 文件，默认 Git 忽略；受控测试输入中即使出现敏感标记，也不会复制进候选。白名单证明仅限此合同，不是通用匿名化保证。

## 隔离、去重和恢复

先按来源家族、实体与原文哈希检查 train/eval 关系，再按规范化输入去重。跨 split 的任一共同来源或相同输入均隔离两侧；相同输入对应不同目标也隔离两侧。相同 split 的重复只留一行，其他 provenance 保留为重复拒绝记录。来源别名、任务重跑和新 ID 不能变成独立样本。

隔离范围是一次传入的完整批次。失败与 unknown 的 eval 来源仍参与分组；无法核验的 eval 分配会阻断本批所有原本可接受的候选。本轮没有跨批次永久 split 注册表，也没有近重复语义检测；不能将分别构建的数据拼接后声称仍然隔离。真实采样前必须冻结并校验全局语料清单与分区。

构建时按持久 store/loop 身份排序并持有原 Runtime 锁；从当前 Runtime 重新投影，验证 T0 capture 成员关系、签名 blob 和 Evidence 绑定。异步主机批准之后及原子发布之前再次校验。数据、审计、批准以单个签名不可覆盖文件发布；相同数据与审计产生相同文件身份，重复导出仍需新的当前许可。

SIGKILL 留下的临时文件不是候选，保留现场；原锁不会自动抢占，必须按已有恢复合同确认死进程并显式恢复锁。构建不调用模型或工具，不退还 unknown 费用、不自动对账、不自动重发。断电、磁盘损坏、多机锁、主机/签名密钥完全失陷或同一用户恶意修改代码不在证明范围。

## 数据就绪条件

格式合法、执行可信、固定策略一致、许可明确、没有泄漏，是候选的必要条件，仍不充分。T1 恒定标记 `BLOCKED`，因为只覆盖两个状态，没有独立未见策略评测，未测学习增益。任何以后放行训练的决定须建立新版本合同与独立研究证据；不能把当前标记改成成功来推进采样。
