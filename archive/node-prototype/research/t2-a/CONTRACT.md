# T2-A 独立金融研究决策合同

唯一实现基线为 T1 `508d0f1`。本合同是**一次下一行动决策**的离线 Benchmark，不是修改版 M4，不是正式新工具或多轮自主研究。T1 `TRAINING_READY=BLOCKED` 不变；继承的 84 个 JS/MJS、Gold、测试断言和历史协议不变。

## Task / Observation

共同目标：判断同一企业两期年度合并毛利率是否可比，在条件满足时计算毛利率及百分点变化。只使用封闭、人工编写的结构化合成数据，不能把它当作外部财报的核验。

Observation 包含目标期间与口径、已保留报表的营收/毛利、各自期间/单位/币种/范围/口径、来源类型与版本声明、可用资料目录、当前允许行动和任务读取额度。没有任务 ID、实体名、split、家族、seed、来源 hash、Gold 或资料未来正文。策略获得同样的 JSON 字节与相同主机政策；任务实体和来源身份保留在受保护记录中。

`remainingReads` 是任务当前允许读取上限，并与主机配置上限相交；**不是全局账户余额**。全局持久读取额度另由原 ModelBudgets 原子检查，可能在提议后阻断操作。不能用新的任务身份重置同一主机/根目录中的额度；跨根/多机器额度统筹未实现。

## 实验行动与实际实现

| 行动 | 当前真实执行内容 | 边界 |
| --- | --- | --- |
| inspect.comparability | 复查已有报表的期间/口径/单位等关系，读取获准资料元信息 | 实验诊断，无事实 Gold |
| read.supplement | 从绑定的合成资料目录读取已保存正文对象 | 不联网，不保证补全，不自动更新研究状态 |
| inspect.revisions | 保留多个版本声明与可访问重述说明 | 不因 edition 较大而自动选数值；不赋予真实来源独立证明 |
| normalize.units | 明确 ones/thousands/millions 的同币种数量级转换，并检查整数边界 | 不猜 FX，不折算期间，不合并分部 |
| calculate.margin | 合成样本的 grossProfit/revenue*100 及两期差 | 新实验算术，非原 Evidence Authority 授权计算或风险计算 |
| report.insufficient | 报告当前阻断因素、任务读取额度与可用补证情况，结束本次决策 | 执行成功不代表研究目标完成 |

所有行动参数为空；策略不能指定路径、URL、来源、实体、权限、风险值或完成标签。主机选定 corpus 与策略，校验身份、授权版本、任务及观察指纹。正式 Runtime 仍只有原 Evidence 工具，M4 的 `expectedAction` 完整保留。

同一期利润与营收必须具备相同币种、期间、合并范围及口径。两期分别使用不同币种并不自动妨碍无量纲毛利率比较；若同一期分子/分母币种不同且无获准转换依据则阻断。当前冻结样本只覆盖非负毛利；实现的负毛利拒绝规则不能推广为真实金融有效性判断，扩展亏损企业需要新版本研究。

## Verifier 与四种质量

`gold.json` 在策略实现前独立手写、封存。它给出可接受集合、禁止集合、原因与少量人工算术答案；verifier 不导入策略、诊断器或 M4 决策函数。没有以策略准确率作为测试 PASS 阈值。

- 合法性：动作格式、工具注册和当前任务读取权限。工具存在并不等于计算前置条件已满足。
- 策略合理性：是否属于冻结的人工可接受集合。这个集合仍可能漏标，不能等同最优策略或完整专家共识。
- 执行完整性：是否存在与 intent/proposal/action/当前证据一致的签名结果，且可重新投影验证。
- 金融事实：仅明确的合成答案可以核验算术一致性；真实世界事实恒为 `NOT_PROVEN`。

读取或诊断执行完成，只能说明下一动作已完成；10 个问题任务没有在本轮自动形成最终金融结论。未知结果、越权和篡改没有可接受的执行样本。T2 不调用 T1 builder、不自动构造训练数据、更不升级训练就绪。

## 持久身份、预算与未知

研究记录由未改动的 DurableTaskStore 的 HMAC、CAS、历史、witness 和原锁保护；自有 schema/version 与旧任务严格区分。任务身份由语料指纹、case、策略和主机主体决定。每次本地策略提议使用独立 `:decision:1`，读取使用 `:read:1`，主机授权、工具政策、观察、证据、预算边界全部绑定。

调用 / 读取预留复用原 ModelBudgets，费用为显式合成零费用，输入 byte+128 只用于人工额度压力；不是真实 Token 或计费保证。所有提议是离线脚本函数；新 receipt 是 benchmark-proposal/action 类型，不能冒充 M2 供应商模型收据。

过程为 intent → 原子额度预留 → 提议 → 签名 proposal 收据 → 权限重验 → action-started → 实验动作 → 签名 action 收据 → 当前验证。中断的 pending/action-started 状态转为 unknown；不自动重发提议或重做动作。存在收据文件也不自动确认，必须显式提交可信、精确匹配的签名引用。无结果收据则继续阻断；unknown 预留与 lease 保留。

重复 / 并发使用同一身份与一次结果；已完成记录重新验证后返回，不改历史。当前权限撤销、错主体、错 grant、状态/结果/历史篡改均保守拒绝。SIGKILL 后先按原机制确认死进程并恢复锁；它不证明断电或磁盘故障一致性。可信本地主机与签名密钥被攻破不在保证范围。

## 来源与冻结

真实原模块控制实验：原 Authority 拒绝未注册合成实体的 contextual/risk 权限；原注册 MiniMax 合成夹具仍通过原提取、Authority 和算术，毛利率 17.85%。这两个控制不把新实验计算升级为正式能力。

6 个配对家族分属 train/dev/eval 的 2/2/2；12 个任务不等于 12 个独立研究问题。精确正文、实体、来源家族、期间、声明模板家族和关系指纹做跨分区检查；反事实保持同分区。关系指纹发现两个 train 完整性控制等价，公开报告保留。JSON Observation 模板和基本检查技能跨分区共享，设计者知道所有场景；不能声称双盲、严格模板隔离或外部语义无泄漏。

`freeze.json` 固定语料 / 原 Gold / 预注册。`strategy-freeze.json` 固定首次评测的策略与诊断实现。一次权限结果投影工程修复记录在 `engineering-repair.json`，保留原源码和诊断同一性检查，未变策略、语料或 Gold。研究发现的漏标和 H4 不成立只进入报告，不能改冻结标签制造更高分。

原始记录、签名密钥、收据、失败现场只保存在 Git 忽略的 0700 / 0600 本地目录；仓库只准备合成 corpus、合同、代码与脱敏摘要。当前公开合成 Gold 不宜直接作为未来 Student 的永久秘密评测集；真实采样须独立冻结、隔离与复核使用权。
