# T2-B isolated multi-step experiment v1
Not a production Harness expansion. All 92 T2-A JS/MJS and frozen histories remain byte-identical.
One goal: compare two annual consolidated IFRS gross margins. Closed synthetic source bodies, no real financial truth.
Six original T2-A experimental tools and exact empty arguments remain unchanged. Each round delegates actual authorization, bounded proposals/reads, signed receipts and conservative unknown to a subclass of BenchmarkExecutor; only trusted source registry create/authorize is adapted. Existing run/reconcile/gate/execute/budget logic is inherited unchanged.
Outer episode uses DurableTaskStore history/CAS/witness. It stores initial source fingerprint, host policy, pending round identity, before observation and confirmed after-state. Each round gets a distinct task identity and proposal/read intent. Same episode resumes existing round; unknown blocks until explicit receipt reconciliation, never retried. A finished round can be installed after a crash only through revalidated original signed receipts. Current principal/host policy must match on all resumes.
Reducer: read.supplement replaces ONLY periods actually present in published document statements; old evidence remains in signed history. Each read releases ONLY linked catalog metadata, not future bodies. normalize installs the actual returned statements. inspect.comparability retains diagnostics but no financial replacement. inspect.revisions selects a newer edition ONLY from a read restatement-note explicitly confirming supersession and matching current period/old/new editions and exact new statement; ambiguous/unconfirmed notes do not resolve conflict. Version ordering alone cannot activate evidence.
Inspection tools are available once per evidence fingerprint (common to every strategy); no-repeat availability is an environment contract, not a change to the old heuristic. Reads consume remainingReads and immutable shared per-episode budget; sources already consumed are removed. Proposal limit four. Runtime termination distinguishes calculated, insufficient, unfinished/cap-exhausted, denied and unknown.
Observation is only original T2-A observation projection: goal, active statements, currently published catalog, current actions/reads. No entity/task ID, partition, source hashes, seeds, Gold, hidden release bodies or terminal answers. Host keeps source identity and document queue outside policy callback. This is logical API isolation, NOT OS sandbox against malicious trusted JavaScript.
Gold v2 independent verifier does not import policy, environment diagnostics or Runtime completion. Seven dimensions separate legality, relevance, acceptability, partial preference, cost, completion and synthetic facts. A successful stop is not a completed numerical goal. Real-world facts always NOT_PROVEN.
Public Git: reviewed code/contracts/synthetic cases/sanitized aggregate results. Raw traces, keys, receipt/witness state and failures only in ignored 0700/0600 local roots. No dataset training export, no permission migration, no real provider.


Any acquisition retains existing multi-edition conflict unless an explicitly confirmed exact-binary supersession proof resolves it. An unconfirmed note cannot overwrite conflicts merely by returning one row. Local safe stopping after self-induced exhaustion is not task-level research success. Financial task-level Gold is authored for the frozen three-read/four-action policy; other policy changes are safety experiments, not interchangeable scored labels. All policy observations are canonical JSON, equally for the unchanged T2-A heuristic; period-key order is never decision information. Dead process locks require explicit verified recoverLock before resumption.
