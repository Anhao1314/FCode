# T1 最小可证伪实验与研究结论

问题不是“能否把日志转成 JSON”，而是哪些监督来自环境验证，哪些只是模型或程序的说法。

## 实验设计

使用原 M3-A 注入式 DeepSeek HTTP、M4 Loop、T0 Recorder，以及真实 Evidence 提取、Authority 与确定性计算。输入仅为已存在的人工财务 HTML 或明确构造的空来源；不发送外部请求、不读取真实凭证。所有真实运行在测试入口创建的独立目录中，失败与成功日志分开保留。

| 组别 | 输入 / 干预 | 事先要求 |
| --- | --- | --- |
| 两种动作 | 原财务夹具；空夹具 | 分别 assess / reread；独立标签，不声称金融 Gold |
| 重复运行 | 同一财务来源不同任务，重启、并发导出 | 一行；不重复调用或制造样本 |
| 来源隔离 | 同家族财务夹具分属 train/eval | 两侧都拒绝 |
| 语义隔离 | 不同实体与家族的空夹具分属 train/eval | 规范化输入相同，两侧都拒绝 |
| 错误策略 | 非空观察后继续 read | 原 Runtime 拒绝，不进入正向 SFT |
| 越权 | 提议 finance.trade | 原工具门控拒绝，零工具执行 |
| 未知 | 第二次模型调用返回 HTTP 503 | 保留 unknown 额度与 lease，零样本，重启不重发 |
| 污染 / 篡改 | 伪造 capture、改 blob、改导出、错来源、错许可、未来标签 | 拒绝且保留失败现场 |
| 发布竞态 | 批准中撤销权限；SIGKILL 于发布前 | 不释放候选；显式恢复后只发布一次 |

固定动作对照只在两行候选上描述：永远 read 为 1/2，永远 assess 为 1/2，独立条件规则为 2/2。它说明两种反馈要求不同动作；不能作为模型准确率、泛化效果或训练提升。动作标签必须来自实际成功执行的 Plan，再与 oracle 比较，不能直接把 oracle 生成的数据冒充 Teacher 轨迹。

## 从实验获得的研究判断

去掉身份和未来信息后，当前所有有效上下文只剩“有 / 无事实”两个状态。重复任务不能增加独立信息。即使空夹具换了实体与来源家族，输入仍相同；保守隔离下不能形成未见评测集。这是本轮刻意保留的失败结果，不靠放松去重或把来源 ID 塞回输入来制造评测。

因此，两行数据是可信的**窄策略候选和管线验收样例**，不是足以训练 Student 的数据集。当前信息下，一条可读的规则已经解决全部目标；没有证据说明为它训练模型值得。对“适合后续模型训练”的回答是：具备可追溯监督与安全格式，但学习价值与外推有效性尚不满足放行条件。

下一代 Student 值得学习的是证据约束的研究动作：观察到什么、还缺什么、哪个获准只读工具能补足，以及什么时候应报告证据不足。扩大前需要一个新研究合同，明确给模型足够但受控的观察信息，以及能由独立验证器区分的多个真实决策状态。不能在 T1 擅自改变已验收 Runtime 或增加工具。

## 真正训练前仍缺什么

1. 有学习价值的非平凡任务分布：不同证据缺口、矛盾、时间范围和工具可用性；先证明规则基线的局限，且标签验证不依赖 Teacher。
2. 按实体、来源、原文、时间及任务模板划分的冻结评测集，评测数据不能回流到采样提示或训练构建；变体和近重复需要比当前精确检查更强的审查。
3. 外部金融事实的独立核验标准与不确定性标签；算术正确、流程完成和研究结论正确分别报告。
4. 足够独立样本和重复研究，控制数据量、长度、模型、训练预算等变量，最后用未见集比较；本轮没有模型训练，因此没有样本复杂度或性能提升证据。
5. 数据使用权、保留期限、主体权利、敏感信息审查与可撤销血缘，真实数据不得继承合成许可。不能决定仓库根许可证。

当前 SFT 目标是实际行动的语义投影，只有 tool 与 arguments；它不是原 Model API 的完整 Plan wire 格式，也不是可直接执行的命令。真正接入 Student 前还须固定 tokenizer / chat template / 输出格式与严格 Plan 合同的对齐方案，并通过原 Runtime 门控验收；本轮不实现转换器或训练管线。

## 下一阶段真实 DeepSeek Teacher 采样的最小条件

先解决一个明确的工程阻断：当前 T0 facade 与 Recorder 仍拒绝 live 模式，抛出 `T0_OFFLINE_ONLY`；本轮完整保留该门控。真实 Teacher 轨迹采集需要另行设计、审查并验收 live provenance、数据许可和费用状态合同，不能仅提供 Key、切换模式或使用内部装配绕过限制。

另行批准采样范围、任务和费用；主机独占模型/工具/预算授权与凭证注入。重新核对当时官方模型标识、价格、Token 上界和供应商数据条款；真实计费与断电保证仍未证明，不沿用离线估算作保证。先冻结独立来源许可、数据留存策略、任务 oracle 和 unseen split，再做极小、可停止的样本审计。输出异常、unknown、授权撤销一律保守恢复，不能重发碰运气。首批原始 Teacher 轨迹必须留在受保护本地，不等于获准训练或公开。

## 研究依据与推断边界

[ReAct](https://arxiv.org/abs/2210.03629) 研究动作与环境观察的交互；T1 只借用可观察动作序列，不采集隐藏推理。[AgentBench](https://arxiv.org/abs/2308.03688) 以交互环境评估 Agent，支持把流程行为与单次文本格式分开观察。[Datasheets for Datasets](https://arxiv.org/abs/1803.09010) 提倡记录数据来源、组成、用途与局限。它们不证明本项目的模型学习效果；上述结论来自本地合同和本轮离线实验。
