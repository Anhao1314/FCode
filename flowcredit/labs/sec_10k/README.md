in the lab or production planner.

## Text pipeline

`html_to_text.py` uses only `html.parser`:

- each block element (`div`, `p`, `h1`–`h6`, `li`, etc.) becomes one line;
- each table `<tr>` becomes one line; cells are joined with ` | `;
- leading/trailing empty cells are trimmed, interior empty cells are kept so
  numeric columns stay aligned;
- parentheses negatives, `$`, `%` and commas are preserved;
- line numbers are 1-based and stable for the same HTML.

`fetch.py` selects six deterministic ranges from the full text by exact headings
and end prefixes:

1. audit report heading → the `In our opinion` paragraph;
2. `Consolidated Balance Sheets` → `TOTAL LIABILITIES AND EQUITY`;
3. `Consolidated Statements of Operations` → `NET INCOME`;
4. `Consolidated Statements of Cash Flows` → `Net cash provided by operating activities`;
5. the MD&A `Total debt |` line with four lines of context;
6. `12.Borrowings` → the first `Total |` in the short-term-debt note.

The excerpt is 122 lines, within the 80–150 requirement.

## Extractor rules

`extract.py` is deterministic and standard-library only:

- split the excerpt by its `###` section markers;
- find a fact's line by its exact label prefix inside the correct section;
- take the first numeric cell after the label for the current year and the
  second for the prior year (skip `$`, `—`, empty cells);
- parse parentheses as negative and take the absolute value for
  `interest_expense`;
- classify `audit_opinion` with negative signals first:
  `disclaimer` → `adverse` → `qualified` → `standard_unqualified`; ambiguous
  text returns `None`, never a default standard;
- select the opinion paragraph by `in our opinion` / `do not express an opinion`
  / `disclaimer of opinion` before a `Basis for …` heading; `except for` alone
  is not a selector, so an `except for` elsewhere does not qualify a standard
  opinion;
- no LLM, no third-party HTML/PDF library, no XBRL. Every value comes from the
  committed HTML-derived excerpt.

If a section or label disappears, or an audit paragraph is ambiguous, the fact
returns `status: "missing"` with a reason and no value; it never falls back to a
guess or zero.

## Credit world and memo

`world.py` presents the extracted filing through the production
`CreditWorld` interface, so the production `CreditPlanner`,
`verify_observation` and `memo.build_memo` are reused unchanged:

- `doc_10k_fy2025` (alias `doc_ar_fy2025`): current column;
- `doc_10k_fy2024` (alias `doc_ar_fy2024`): comparative column;
- `doc_debt_fy2025`: MD&A total debt + Note 12 short-term debt;
- `doc_rating_fy2025`: missing (10-K has no rating migration report).

EBITDA proxy = `operating_income + depreciation_amortization` = 11,760 + 2,811 =
14,571 million. Computable metrics:

| metric | value |
| --- | ---: |
| net_debt_to_ebitda | 13552 bp (1.36x) |
| interest_coverage | 91469 bp (9.15x) |
| ocf_to_short_term_debt | 27127 bp (2.71x) |
| receivables_to_revenue | 1183 bp (11.83%) |
| audit_opinion | `standard_unqualified` |

Missing metrics: `related_party_funding_ratio`,
`contingent_liabilities_to_equity`, `rating_migration`. The 10-K does not
disclose a related-party loan total, a single contingent-liability total, or a
rating migration; these are returned as blocked, never zero. This is product
semantics, not an extraction bug — the memo is `issued: false` and
`decision_status: blocked` because the evidence is incomplete, not because the
extractor failed.

The memo is therefore:

```text
recommended_conclusion = insufficient_evidence
conclusion_authority  = policy
decision_status       = blocked
issued                = false
signed                = false
verified              = false
missing               = [related_party_funding_ratio,
                         contingent_liabilities_to_equity,
                         rating_migration]
```

The memo JSON/Markdown are written under `work/sec_10k/` (gitignored). The memo
markdown is marked **真实公开数据（SEC 10-K），仅用于 FCode 抽取研究；不构成任何
信贷或投资意见**, and the JSON has `synthetic: false`, `research_only: true`,
`source_url`, `accession` and `cik`.

## Tests

`tests/test_sec_10k_extract.py` covers:

- 21/21 fact value, unit, source_unit, period, doc_id, line and snippet equality;
- excerpt readback for every extracted citation;
- prior-year facts are extracted from the comparative column, and the FY2024
  world document uses those values rather than constants;
- standard / qualified / adverse / disclaimer audit opinions classify correctly;
  ambiguous text returns `None`; an `except for` outside the opinion paragraph
  does not qualify a standard opinion;
- a missing fact returns missing and no value;
- missing rating/related/contingent metrics stay blocked;
- the spike `ok` and the blocked memo state;
- real-data memo metadata (`synthetic: false`, `research_only: true`).

## Limits

- One issuer, one filing; not a 10-issuer evaluation.
- No XBRL fallback; the HTML table rules are intentionally narrow.
- No rating report, related-party note or single contingent-liability total in
  this filing; those facts are missing by design, not extraction failures.
- No real LLM; the runtime still uses the deterministic mock provider.
- The real company name appears only for traceability; the memo is research-only
  and makes no credit or investment recommendation.
