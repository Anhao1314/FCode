## 五个研究问题

**Q1：存在实质复杂度吗？** 是。缺失指标、来源证明、可转换/不明数量级、期间错配、重述冲突、范围/币种组合和读取额度，导致不同受控行动。不是靠任务 ID 或增加重复轨迹制造选择。然而这里只是一次决策环境，不证明正式 Agent Loop 已获得新自主能力。

**Q2：评分独立吗？** 手写集合在策略前冻结，verifier 不导入任何策略/诊断函数，不以模型或 Runtime 完成作为事实 Gold。实现层面独立成立；标注覆盖仍 **INCONCLUSIVE**：c0 的获准 notes 已可提供正确单位的报表，read.supplement 是可辩护路径，却被原 Gold 排除。Root 实际执行并记录“合法且执行完整、策略得分为假”的反例，未修改 Gold。没有独立财务专家共识或外部事实核验。

**Q3：未见可靠且无泄漏吗？** 可核验的限制范围内无跨分区实体、来源、期间、精确正文或关系指纹交叉；反事实保持同分区，策略输入剥离标识/Gold/未来正文。train 两个完整性控制的语义重复被报告。**不能证明严格未见或语义无泄漏**：相同 JSON 输入模板和基本技能共享；模板家族只是声明的机制分组；设计者知道所有场景，eval 仅两个家族且 Gold 在本地代码候选可见。预注册 H4 的模板不重叠部分不成立，原文本不改。当前只能称冻结未用于调分的结构组合，不是双盲泛化评测。

**Q4：简单规则能完全解决吗？** 在当前 12 个冻结标签上，是，启发式与候选持平。这个结果证明对这些标签规则足够，不能叫真实研究的最优性上界。候选共享环境 diagnose，启发式独立复述规则；两者均为人写程序，无 Teacher/Student 实验。

**Q5：值得真实 Teacher 实验吗？** 当前不值得。先需要新版本的合理行动覆盖/成本标准、独立作者的未见任务与来源、真实金融资料许可、亏损/负毛利等边界复核，以及规则基线确实不足的任务证据。本轮不能通过改 Gold、放松隔离或人为复杂化来论证模型有优势。

真实采样还要单独验收 live Recorder（原 T0 仍拒绝 live）、主机凭证与预算授权、当时模型/价格/供应商条款、使用权及数据保留、明确 unknown 对账与停止条件。即使批准采样，也不自动等于批准训练或发布。
